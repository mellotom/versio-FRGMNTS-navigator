# versio-frgmnts-navigator

travelers guide for fragmenting time: a one-page reference for **frgmnts versio**, acidclank’s live multi-effect firmware for the versio platform: stutter, tape, filter and wash. every knob by its number, the clock and bypass, each effect drawn out, and what changed in 1.2. firmware: https://acidclank.gumroad.com/l/frgmntsversio

source: the acidclank frgmnts versio manual v1.2.

part of the [versio starsystem](https://mellotom.github.io/versio-navigator/) in the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).
